# ひぐらし 公式サイト

バンド「ひぐらし」の紹介・ライブ予定・出演依頼のためのWebサイト。現在制作・改善中です。

## 目的
ファンとライブハウスのブッキング担当者に、演奏とコンセプトを伝え、ライブ来場や出演依頼につなげることを目指しています。

## 機能
- スクロールに合わせたライブ映像とコンセプトの表示
- 冒頭の3秒後の自動スクロール（操作時はキャンセル）
- ライブ予定ページ
- 出演依頼メールの下書き作成・コピー
- スマートフォン向けレイアウト

## 制作について
バンドメンバーが目的・構成・導線・表現方針を考え、生成AIを活用して実装と改善を進めています。コンセプト文やライブ予定には仮枠が含まれます。

## 公開方法
このフォルダの中身をリポジトリ直下にアップロードし、Settings → Pages → Deploy from a branch → main / (root) → Save を選択します。

index.html と assets フォルダは同じ階層に置いてください。公開後もファイルの更新で同じURLに変更を反映できます。Releasesの作成は不要です。

## 更新する場所
- トップ・コンセプト：index.html
- ライブ予定：live.html
- 出演依頼：booking.html
- 画像・映像：assets/
